# 🌐 Personal Portfolio Website

A modern and responsive Portfolio Website developed using React and Vite to showcase my skills, projects, certifications, coding profiles, and professional achievements.

The portfolio is designed to provide recruiters and visitors with a complete overview of my technical expertise, project experience, and career journey.

---

## 📌 Project Overview

This portfolio serves as my professional digital presence, highlighting my development skills, projects, certifications, coding profiles, and contact information.

It features a clean UI, responsive design, smooth navigation, and modern animations to create an engaging user experience.

The application is built using React and Vite.

---

✔️ Responsive Modern Design

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone <repository-link>
```

### 2. Navigate to Project Folder

```bash
cd PORTFOLIO
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open Browser

```text
http://localhost:5173/Portfolio/
```
